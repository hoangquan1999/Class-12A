# Website Thiệp Mời Kỷ Yếu Lớp 12A (Đã Cập Nhật Bảng Lưu Bút & Danh Sách)

Website thiệp mời chụp ảnh kỷ yếu dành riêng cho tập thể lớp 12A với thiết kế Retro/Vintage sang trọng, bổ sung bảng lưu bút và danh sách đăng ký tham dự trực tiếp.

## Cấu trúc thư mục

```text
Website-KyYeu-12A/
├── index.html            # Trang chính thiệp mời kỷ yếu
├── assets/
│   └── thanh-xuan.mp3    # File nhạc nền (Chép file mp3 của lớp vào đây)
└── images/
    └── readme.txt        # Thư mục lưu trữ hình ảnh kỷ yếu
```

## Tính năng mới bổ sung

1. **Sổ Lưu Bút Online (Live Guestbook):** Tự động hiển thị lời chúc gửi tới tập thể 12A ngay sau khi khách bấm "Gửi xác nhận".
2. **Danh Sách Tham Dự Cập Nhật Trực Tiếp:** Tự động tổng hợp số lượng và tên thành viên/thầy cô đã xác nhận có mặt.
3. **Lưu trữ dữ liệu tự động (LocalStorage):** Giúp lưu giữ lời chúc và danh sách đăng ký ngay trên trình duyệt mà không bị mất khi tải lại trang.
